HIGHWAY RACING 3D — ANDROID PROJECT
===================================
Engine: Godot 4.x (free)

WHAT'S INCLUDED
- Procedural 3D highway, lane markings and guardrails
- Player sports car and traffic vehicles
- Automatic forward driving, lane steering, brake and nitro
- Collectible coins, score, speed display and crash/restart flow
- On-screen touch buttons plus keyboard controls for testing
- No paid assets or external plugins required

IMPORTANT
This is a playable starter project with stylized procedural 3D graphics. It is not a clone of CarX and does not include licensed CarX assets. For a more photorealistic finish, replace the procedural cars/road with licensed 3D models and textures.

OPEN ON COMPUTER
1. Install Godot 4.x Standard from https://godotengine.org/download
2. Extract this ZIP.
3. Open Godot Project Manager > Import and select project.godot in this folder.
4. Open the project and press F6 or F5 to play.

BUILD AN ANDROID APK
1. Install Godot 4.x Standard on a computer.
2. Install Android Studio / Android SDK and the JDK version recommended by your Godot version.
3. In Godot, open Editor > Editor Settings > Export > Android. Set the Android SDK path and Java SDK path.
4. Download/install the Export Templates matching your exact Godot version: Editor > Manage Export Templates.
5. Project > Export > Add... > Android.
6. In the Android preset, set package name to com.yourstudio.highwayracing3d, set version name/code, and choose an app icon if you have one.
7. For a test APK, enable the debug option / export as debug, then click Export Project and save HighwayRacing3D.apk.
8. Copy the APK to your Android phone, allow installation from that source when prompted, and install.
9. For Google Play, create a release keystore, configure signing, and export an Android App Bundle (AAB), not a debug APK.

PHONE CONTROLS
- ◀ / ▶: steer left/right
- BRAKE: slow down
- NITRO: temporary speed boost
- Keyboard A/D or arrows, S for brake, Space for nitro when testing on PC.

TROUBLESHOOTING
- If Android export is unavailable, install the matching export templates.
- If SDK/JDK errors appear, use the paths shown by Android Studio and restart Godot.
- Test first on a real phone; performance varies by device.

LANDSCAPE DISPLAY
The project is configured for landscape orientation (1280x720).
